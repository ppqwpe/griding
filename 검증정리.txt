Griding 검증 정리 (2026-10-29)

■ 무엇을 하는 툴
  실사 플레이트의 사람 얼굴을 격자 · 검정 가림 · 표정 점/선으로 덮어서 시댄스에 넣을 수 있게 만든다.
  ComfyUI 없이 Windows 에서 Griding.bat 하나로 돈다 (파이썬 · 모델 · ffmpeg 모두 폴더 안).

■ 쓰는 모델
  머리 찾기    YOLO11s / YOLO11m head (deepghs) · 그래픽카드(DirectML) 또는 CPU
  사람 잇기    ByteTrack 방식 (모델 없음, 직접 구현)
  표정 찾기    Google MediaPipe Face Landmarker (얼굴 점 478개) · CPU
  읽기 · 저장  FFmpeg (H.264 · PNG 무손실 MOV)

■ 2. 원본 → 결과 규격 (같게 나오는지 실제로 잼)
  해상도 · fps · 프레임 수   원본과 같음 (217프레임 · 1920×1080 · 24fps, 23.976 등도 정확히)
  색                         고치기 전: 709 영상을 601 로 읽고 저장도 2.5단계 어두웠음
                             고친 뒤: 밝기 치우침 +0.05, 평균 차 약 1 (H.264 압축 손실만) · 색공간 표시 붙임
  소리                       AAC·MP3·AC3 는 그대로 복사, PCM 등은 AAC 로 변환
  회전 · 가변 fps · 홀수 크기 회전 적용 · 고정 fps 로 맞춤 · mp4 만 1px 짝수 (레이어는 원본 크기)
  저장 뒤 대조               파일마다 프레임 · 크기 · fps 를 원본과 비교해 화면에 '✓ 원본 규격과 같음'
  비트레이트                 고정 CBR — 2K 30Mbps · 4K 50Mbps (또는 원본 값 그대로 고정)
                             실측 1080p: 평균 29.7Mbps · 초마다 27~33 / 원본 15.1 그대로 → 15.0Mbps

■ 3. 카드별 투명 레이어 (H.264 압축 없이 편집기에서 합치기)
  _layer1_xxx.mov … PNG 무손실 · 투명 배경 · 원본 크기 · 같은 프레임 수
  원본 + 레이어를 번호 순서대로 쌓은 것 = 조합 결과 (평균 차 1.1~1.3, 조합 쪽 H.264 손실)
  1080p 9초 기준 레이어 하나 4~5MB
