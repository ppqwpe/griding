Griding 1.0 사용법

실사 플레이트 속 얼굴을 격자나 가림으로 덮어 시댄스에 넣을 수 있게 만드는 앱입니다.
설치할 것은 없습니다. Windows 10/11 이면 됩니다.


■ 켜기

Griding.bat 을 두 번 누르면 검은 창이 뜨고, 이 PC 점검이 끝나면 브라우저에 화면이 열립니다.
처음 켤 때 바탕화면에 Griding 바로가기가 생기니 다음부터는 그걸 누르면 됩니다.
그래픽카드 때문에 멈추거나 꺼지면 Griding_CPU.bat 으로 켜세요. 결과는 같고 조금 느립니다.

작업하는 동안 검은 창은 닫지 마세요. 브라우저가 안 열리면 검은 창에 나온 주소
(http://127.0.0.1:7860/ 같은 것)를 크롬이나 엣지 주소창에 붙여넣습니다.
화면 오른쪽 위 [한국어 | English] 로 언어를 바꿀 수 있습니다.


■ 순서

① 플레이트 넣기
   영상이나 이미지를 끌어다 놓습니다. 여러 개를 넣으면 차례로 처리합니다.
   넣으면 원본 아래에 해상도, fps, 길이, 색공간, 소리가 나오고, 알아둘 점이 있으면 노란 글씨로 알려 줍니다.

② 사람 확인
   넣자마자 영상 전체에서 사람을 찾아 #1, #2 … 번호와 얼굴 썸네일을 보여 줍니다.
   가릴 사람만 남기고 나머지는 눌러서 뺍니다. 컷이 바뀌면 같은 사람도 새 번호를 받습니다.

③ 카드 골라 조합하기
   예시 조합 버튼(격자만, 가린 표정 가이드 …)으로 시작하거나 카드를 눌러 쌓습니다.
   나중에 고른 카드가 위에 덮입니다. 순서는 [쌓인 순서]의 ↑↓ 로 바꿉니다.
   바탕은 원본 위 또는 검은 바탕 중에 고릅니다.
   [고른 카드 설정]에는 고른 카드의 설정만 나옵니다. 가림과 격자는 색 팔레트와 불투명도를 따로 정합니다.
   플레이트를 넣기 전에는 예시 캐릭터로 미리 보여 줍니다.

④ 내보내기
   만들 파일에 체크합니다. 여러 개 골라도 됩니다.
     조합 영상            고른 카드를 다 겹친 mp4 하나. 시댄스에 넣는 파일
     카드별 투명 레이어    카드마다 투명 배경 MOV 하나. AE, 프리미어에서 합성할 때
     확인용               원본 | 결과 | 추적 비교 영상, 정지 그림, 9칸 시트
   조합 영상 설정
     원본에 맞춤    해상도, fps, 색공간, 소리는 원본 그대로 고정입니다 (자물쇠 표시)
     비트레이트     고정(CBR). [해상도 기준] 2K 까지 30Mbps, 4K 50Mbps / [원본과 같게] 원본 영상 값
     예상 크기      파일 크기를 미리 계산하고 시댄스 200MB 안에 드는지 알려 줍니다
   [규격 자세히]를 펼치면 원본과 결과가 항목마다 어떻게 나오는지 표로 볼 수 있습니다.

⑤ 실행하고 받기
   [이 프레임 미리보기]로 한 장을 먼저 보고, [전체 실행]을 누릅니다.
   끝나면 파일마다 '원본 규격과 같음' 확인과 [받기] 버튼이 나옵니다.
   같은 플레이트를 다시 실행하면 기본으로 01_이름_v2, _v3 … 새 폴더에 쌓입니다.
   [같은 폴더에 덮어쓰기]로 바꿀 수도 있고, 작업 목록의 [다시 실행]으로 그 플레이트만 다시 만들 수 있습니다.


■ 카드

  가림 · 얼굴 윤곽   얼굴 윤곽을 조금 넓혀 덮습니다. 표정을 못 찾은 옆모습과 뒤통수는 머리 박스로 덮습니다
  가림 · 머리 전체   귀와 머리카락까지 머리 전체를 덮습니다. 표정 인식 없이도 됩니다
  격자               머리 위에 격자를 얹습니다. 모양 8가지 (격자, 대각선 격자, 가로줄, 세로줄, 점, 체크, X 십자, 박스 채우기)
  표정 선            눈, 눈썹, 입, 코, 얼굴 윤곽 선 (기본 빨강)
  표정 점            얼굴 점 478개 (기본 빨강)
  추적 박스          찾은 머리 박스와 번호. 초록은 찾은 것, 주황(HOLD)은 잠깐 놓쳐 유지한 것

  가림 불투명도를 100%보다 낮추면 원본 얼굴이 비칩니다. 얼굴이 보이면 시댄스가 거절할 수 있습니다.
  표정 선과 점은 눈과 입이 보이는 정면~반측면에서만 잡힙니다. 완전한 옆모습이나 뒤통수 프레임은 비어 있는 게 정상입니다.


■ 격자만 뽑기

  ③에서 [격자만 (시댄스)]를 누르면 격자 카드 하나만 들어갑니다.
  조합 영상은 원본 위에 격자, 투명 레이어는 격자만 있는 MOV 로 나옵니다.
  검은 바탕에 흰 격자(격자 매트)가 필요하면 ④ › [그 밖의 결과물]에서 '격자 매트'를 켭니다.


■ 카드별 투명 레이어로 합치기

  이름_layer1_cover_face.mov, 이름_layer2_points.mov … 번호가 쌓는 순서입니다.
  PNG 코덱 MOV, RGBA(투명 배경), 무손실, 원본과 같은 크기와 프레임 수입니다. 소리는 없습니다.
  타임라인에 원본 플레이트를 맨 아래 두고 layer1, layer2 … 순서로 같은 시작점에 올리면(블렌드 Normal)
  조합 영상과 같은 그림이 됩니다. 원본은 10비트 그대로라 H.264 로 한 번 더 압축하지 않습니다.
  1080p 9초 기준 레이어 하나가 4MB 안팎입니다 (재 보니 3.6~4.1MB). 브라우저에서는 미리보기가 안 되니 결과 폴더에서 여세요.


■ 원본 규격은 이렇게 지킵니다

  읽기   원본 색공간(BT.709, BT.601, BT.2020)과 범위(tv, pc) 공식대로 풉니다. 회전 정보가 있으면 돌려서 읽고,
         가변 프레임(휴대폰, 화면 녹화)은 기준 fps 의 고정 프레임으로 맞춰 소리와 어긋나지 않게 합니다.
  저장   해상도, fps(23.976 같은 값도 정확히), 색공간과 색 표시, 화면비(SAR)를 원본과 같게 씁니다.
         소리는 AAC, MP3, AC3 면 다시 압축하지 않고 복사하고, 그 밖은 AAC 192k 로 바꿉니다.
         가로나 세로가 홀수면 mp4 만 1px 늘려 짝수로 맞춥니다 (H.264 규칙). 투명 레이어는 원본 크기 그대로입니다.
         10비트 원본은 mp4 가 8비트가 됩니다. 원래 화질이 필요하면 투명 레이어로 합성하세요.
  대조   저장이 끝나면 파일마다 프레임 수, 크기, fps 를 원본과 비교해 화면에 보여 주고 _settings.json 에 남깁니다.

  실제로 재 본 값 (9초 플레이트)
    2K 고정 → 평균 29.3Mbps · 4K 고정 → 48.8Mbps · 원본 16.5Mbps 그대로 → 16.0Mbps
    색: 가림 없는 곳의 결과와 원본 평균 차 약 1 (0~255 중, H.264 압축 손실), 밝기 치우침 +0.05


■ 결과 폴더

  결과\01_이름\  넣은 순서대로 01, 02 … 다시 실행하면 01_이름_v2
    이름_combo.mp4        조합 영상
    이름_layerN_카드.mov  카드별 투명 레이어
    이름_compare.mp4      원본 | 결과 | 추적 3칸 비교
    이름_preview.jpg      비교 정지 그림 · 이름_contact.jpg 9칸 시트
    이름_settings.json    설정, 입력 규격, 결과 대조, 프레임별 머리 위치
  결과\verification.json  전체 요약

  [그 밖의 결과물]에서 예전 양식 파일도 따로 켤 수 있습니다:
  격자만(_facegrid), 추적 확인(_overlay), 격자 매트(_matte), 가린 표정 가이드(_masked), 표정 가이드(_face),
  표정 추적 확인(_face_overlay), 표정 점(_points + 좌표 _points.json), 표정 점 확인(_points_overlay),
  가리기(_cover), 머리 마스크(_headmask)


■ 잘 안 될 때

  머리를 놓치는 컷        ③ › [머리 찾기 · 넓히기 · 흔들림] 에서 검출 민감도를 0.15 로 낮춥니다
  엉뚱한 곳이 잡힐 때     검출 민감도를 0.35 로 올립니다
  작은 머리, 겹친 사람    머리 검출 모델을 '정확(YOLO11m)'으로 바꿉니다. 2~3배 느립니다
  그래픽카드에서 멈춤     Griding_CPU.bat 으로 켭니다. 작업 중에 드라이버가 멈추면 알아서 CPU 로 바꿔 이어 갑니다
  화면이 예전 그대로      검은 창을 닫고 바탕화면 Griding 바로가기로 다시 켭니다

  켤 때마다 이 PC 를 점검합니다 (화면 맨 아래 '이 PC 점검', work\pc_check.json).
  ✓ 됨, ! 되지만 알아둘 것, ✗ 못 씀 — 못 쓰는 항목에는 할 일이 같이 나옵니다.
    빠른 머리 모델, ffmpeg, 부품이 없으면   켜지 않고 폴더를 통째로 다시 복사하라고 안내합니다
    정확 모델이 없으면                      '빠름' 만 씁니다
    표정 인식이 안 켜지면                   표정 카드만 못 씁니다. 격자와 머리 전체 가림은 됩니다
    앱 폴더에 쓸 수 없으면                  결과는 문서\Griding 결과 로 자동으로 옮깁니다
    zip 안에서 바로 실행하면                압축을 먼저 풀라고 안내합니다

  그래도 안 되면 자가 점검을 돌립니다: app\python\python.exe app\tests\run_tests.py (155개)


■ 다른 PC 로 옮기기

  폴더를 통째로 복사하거나 배포 zip 을 [모두 압축 풀기] 한 뒤 Griding.bat 을 누릅니다. 약 580MB 입니다.
  ComfyUI, 파이썬, Visual C++ 설치, 그래픽카드가 없어도 됩니다.
  그래픽카드가 있으면 종류와 상관없이 DirectML 로 쓰고, 없으면 CPU 로 1.5~3배 느립니다.
  한글이나 공백이 들어간 폴더에 둬도 됩니다.
  내려받기: https://github.com/ppqwpe/griding/releases
