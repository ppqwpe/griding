Griding 1.0 — 시댄스 실사 얼굴 검열 피하기용 격자 · 표정 · 가리기 레이어

■ 쓰는 법 (설치 없음)
  Griding.bat 더블클릭 → 검은 창에 [이 PC 점검] 표가 나오고 → 브라우저에 화면이 열린다.
  처음 켤 때 바탕화면에 아이콘 달린 'Griding' 바로가기가 생긴다 (다음부터 그걸 누르면 됨 · 지워도 다시 안 생김 ·
  폴더를 옮겨 켜면 새 위치로 한 번 다시 만듦).
  (그래픽카드 때문에 멈추거나 꺼지면 Griding_CPU.bat — 결과는 같고 조금 느림)
  ① 플레이트 넣기   영상·이미지를 끌어다 놓는다 (여러 개 한 번에 가능)
  ② 사람 확인       넣자마자 자동으로 영상 전체를 훑어 사람이 몇 명 · 언제 나오는지 보여 준다 (#1, #2 … 얼굴 썸네일)
                    카드를 눌러 가릴 사람만 고른다. 한두 프레임만 잡힌 오검출은 사람으로 세지 않는다
                    컷(장면 전환)이 바뀌면 같은 사람도 새 번호를 받는다
  ③ 카드 골라 조합  카드를 누르는 순서대로 쌓아 결과 한 개(_combo)를 만든다. 다시 누르면 빠진다 (처음엔 아무것도 없음 · 격자도 고를 때만)
                    바탕: 원본 위에 / 검은 바탕 위에 · [쌓인 순서]에서 ↑↓ 로 순서 바꾸기 (아래 줄이 위에 덮임)
                    [고른 카드 설정]에 고른 카드만 나온다. 카드마다 색 팔레트(검정·흰색·회색·빨강·초록·파랑·노랑 + 직접 고르기)
                    와 불투명도 밀대: 격자 선 · 가림 · 얼굴 윤곽 · 가림 · 머리 전체(따로) · 표정 선·점(기본 빨강)
                    플레이트를 넣기 전에는 예시 캐릭터로 보여 준다 (조합 그림은 전신, 카드는 머리)
  ④ 내보내기 고르기 큰 카드 3장 중 고른다 (여러 개 가능)
                    조합 영상 _combo.mp4 (시댄스용) · 카드별 투명 레이어 _layerN.mov (편집기 합성용) · 확인용 (비교 · 미리보기 · 시트)
                    투명 레이어를 켜면 나올 파일 이름과 쌓는 순서가 미리 나온다
                    [입력 → 출력 규격] 표: 원본 · 조합 · 레이어가 해상도 · fps · 길이 · 코덱 · 비트 · 색공간 · 회전 · 픽셀 비율 · 소리별로
                    어떻게 나오는지. 초록 = 원본과 같음, 노랑 = 일부러 바뀌는 곳(칸 아래에 이유)
  ⑤ 실행하고 받기   [이 프레임 미리보기] → [전체 실행] → 결과 칸 아래에 파일이 묶여서 나온다
                    (조합 / 투명 레이어 / 확인용 / 설정) 파일마다 '✓ 원본 규격과 같음' + 실제 프레임 · 크기 · fps · [받기]
                    규격표에도 '실측' 줄이 생긴다
  맨 위 흐름도     넣은 파일 → ①머리 찾기(모델 · 그래픽카드/CPU) → ②사람 잇기 → ③표정 찾기(쓰는지) → ④카드 겹치기 → 저장 → 나오는 파일
                    고르는 대로 바로 바뀐다. 아래 '쓰는 모델 자세히' · '이 PC 점검' 은 눌러서 펼친다

■ 카드 (6장)
  가림 · 얼굴 윤곽   얼굴 윤곽을 넓혀 가림 색으로 덮음. 표정을 못 찾은 옆모습 · 뒤통수는 머리 박스로 덮음 (표정 인식)
  가림 · 머리 전체   귀 · 머리카락까지 둥근 네모로 덮음
  격자               머리 위 격자 (아래 격자 설정)
  표정 선            눈 · 눈썹 · 입 · 코 · 얼굴 윤곽 선 (표정 인식)
  표정 점            얼굴 점 478개 (표정 인식)
  추적 박스          찾은 머리 박스와 번호
  [함께 저장할 파일] 을 펼치면 비교 영상 · 미리보기 · 레이어 따로(격자 · 표정 · 가리기) 도 같이 저장할 수 있다.

■ 카드별 투명 레이어 (압축 없이 편집기에서 합치기)
  [함께 저장할 파일 › 카드별 투명 레이어] 를 켜면 고른 카드마다 파일 하나씩:
    이름_layer1_cover_face.mov · 이름_layer2_points.mov · 이름_layer3_grid.mov …  (번호 = 쌓는 순서)
  규격: PNG 코덱 MOV · RGBA(투명 배경) · 무손실 · 원본과 같은 크기 · fps · 프레임 수 · 소리 없음
  합치기: AE · 프리미어 타임라인에 원본 플레이트를 맨 아래, 그 위에 layer1 → layer2 → layer3 순서로 올린다
          (같은 시작점 · 블렌드 Normal). 이렇게 쌓으면 _combo.mp4 와 같은 그림이 되고,
          원본은 10비트 · 원래 화질 그대로라 H.264 로 한 번 더 압축하지 않는다.
  만드는 법: 카드 하나를 검은 바탕 · 흰 바탕에 각각 그려 둘의 차이로 투명도를 구한다
          → 반투명 격자 · 부드러운 가장자리까지 그대로 (원본 위에 얹으면 카드를 바로 그린 것과 같음 — 검사함)
  용량: 1080p 9초 기준 레이어 하나 4~5MB (빈 곳이 많아 작다). 브라우저에서는 미리보기가 안 되고 결과 폴더에서 연다.

■ 쓰는 모델 (화면 맨 위에도 나옴)
  머리 검출   YOLO11s head (빠름, 기본) / YOLO11m head (정확 — 작은 머리 · 겹친 사람에 강함, 2~3배 느림)
              deepghs/real_head_detection (Hugging Face) · ONNX Runtime · 그래픽카드(DirectML) 또는 CPU · AGPL-3.0
              [머리 찾기 › 머리 검출 모델] 에서 고른다
  추적        점수 2단계 짝맞추기 (ByteTrack 방식, 직접 구현) — 엇갈려도 번호 유지 · 3프레임 이어져야 사람 · 컷에서 새로 시작
  표정 인식   Google MediaPipe Face Landmarker — 얼굴 점 478개 · CPU · Apache-2.0 (표정 카드를 골랐을 때만 돈다)
              겹친 두 사람은 각자 머리 가운데 얼굴만 가져간다
  영상 읽기·저장  FFmpeg (imageio-ffmpeg) · 조합은 H.264 mp4 · 투명 레이어는 PNG MOV
  작업하는 동안 검은 창은 열어 둔다. 다 끝나면 창을 닫는다.
  브라우저가 안 열리면 검은 창에 나온 주소(http://127.0.0.1:7860/)를 크롬·엣지에 붙여넣는다.

■ 규격 — 넣은 파일을 읽고, 나간 파일을 대조한다
  넣으면 원본 칸 아래에 규격이 나온다: 해상도 · fps(가변이면 표시) · 길이 · 코덱 · 비트 깊이 · 색공간 · 소리
  알아둘 점(노란 줄): 10비트/HDR → mp4 는 8비트 · 가변 프레임 → 고정 fps 로 맞춤 · 회전 · 홀수 크기 · 색공간 표시 없음 등
  읽기   ffmpeg 가 원본 색공간(BT.709 / BT.601 / BT.2020) · 범위(tv/pc) 공식대로 푼다. 회전 정보가 있으면 돌려서 읽는다.
         가변 프레임(휴대폰 · 화면 녹화)은 기준 fps 의 고정 프레임으로 맞춰 원본 타임라인 · 소리와 어긋나지 않게 한다.
  저장   _combo.mp4 등: 원본과 같은 해상도 · fps(23.976 등 정확한 값) · 색공간 공식과 색 표시 · 화면비(SAR)
         소리는 AAC · MP3 · AC3 면 다시 압축하지 않고 그대로 복사 (그 밖은 AAC 192k)
         비트레이트는 고정(CBR, 가변 아님): 기본 2K 까지 30Mbps · 4K 50Mbps. [④ 내보내기 › 조합 mp4 비트레이트] 에서
         '원본 영상 비트레이트 그대로 고정' 도 고를 수 있다 (원본 값을 모르면 기본값). 확인용 축소본(_compare)만 화질 기준.
         실측: 1080p 9초 → 평균 29.7Mbps · 초마다 27~33Mbps, 원본(15.1Mbps) 그대로 → 15.0Mbps
         가로·세로가 홀수면 mp4 만 1px 늘려 짝수 (H.264 규칙). 투명 레이어는 원본 크기 그대로.
  대조   저장이 끝나면 영상마다 프레임 수 · 크기 · fps 를 원본과 대조해 _settings.json 의 checks 에 남기고
         화면 결과 칸 · 목록에 '규격 5/5' 처럼 보여 준다. 다르면 빨간 글씨로 무엇이 다른지 알려 준다.
  색 정확도 (실측, 10비트 HEVC 1080p 원본)
         가림 없는 곳 결과−원본 평균 차 약 1 (0~255 중, H.264 압축 손실) · 전체 밝기 치우침 +0.05
         (고치기 전: OpenCV 가 709 영상을 601 공식으로 읽고, 저장도 표시 없이 −2.5 어두워졌었음)
         원본 + 투명 레이어 3장 = 조합 결과 (평균 차 1.1~1.3, 조합 쪽 H.264 손실)

■ 격자 설정 (숫자로 입력)
  세로줄 · 가로줄        줄 개수 (1~32, 기본 5 · 6)
  선 두께 %              머리 폭에 대한 비율 (0.1~20, 기본 2.2) — 가까운 얼굴은 굵게, 먼 얼굴은 가늘게 자동
  선 불투명도 %          0~100 (기본 100)
  칸 채우기 %            칸 안을 같은 색으로 얇게 덮기 0~100 (기본 0)
  색 · 덮는 모양         네모로 덮기 / 타원으로 자르기
  모양 카드              격자 · 대각선 · 가로줄 · 세로줄 · 점 · 체크 · X 십자 · 박스 (지금 숫자 그대로 모양만 바뀜)
  세부 설정              검출 민감도 · 놓쳐도 유지(프레임) · 위/옆/아래로 넓히기 % · 흔들림 완화 %
  범위를 넘는 숫자는 칸을 벗어날 때 끝값으로 맞춰진다. [기본값으로] 로 처음 값으로 돌아간다.

■ 결과 양식 (2026-10-01 강아지 가이드 패키지와 같은 규칙)
  결과\01_이름\  (넣은 순서대로 01, 02 …)
   격자
    이름_facegrid.mp4      격자 · 시댄스에 넣을 파일. 원본 해상도·fps·소리 그대로 (끌 수도 있음)
    이름_compare.mp4       PLATE / FACEGRID / TRACK 3칸 비교 (1920 폭, 칸마다 위 라벨)
    이름_overlay.mp4       머리 추적 확인. 초록 = 검출, 주황 HOLD = 잠깐 놓쳐 유지 중
    이름_matte.mp4         검은 배경 + 흰 격자 (AE 합성용)
    이름_preview.jpg       비교 정지 이미지 · 이름_contact.jpg 결과 3×3 밀착 시트
   표정 트래킹
    이름_masked.mp4        가린 표정 가이드: 얼굴을 검게 가리고 그 위에 초록 표정 점·선 (원본 소리, 기본으로 켜짐)
                           10/01 masked-face-guides 와 같은 방식. 시댄스 Edit 에 넣을 때 쓴다
                           가리는 범위: 얼굴 윤곽만 / 머리 전체(귀·머리카락) · 윤곽 넓히기 % · 가림 색 · 가림 불투명도 % · 점·선 색 (기본 빨강)
                           가림 불투명도를 100% 아래로 내리면 원본 얼굴이 비친다 (투명 레이어에도 같은 반투명으로 저장)
                           표정을 못 찾은 옆모습·뒤통수 프레임도 머리 박스로 가려서 얼굴이 드러나지 않는다
    이름_face.mp4          검은 배경 + 흰 표정 선 (눈·눈썹·입·코·얼굴 윤곽) — 10/01 _face 와 같은 양식
    이름_face_overlay.mp4  원본 위 초록 표정 선 + 얼굴 그물
    이름_points.mp4        검은 배경 + 흰 얼굴 점 478개 + 윤곽선 — 10/01 points_lines 와 같은 양식
    이름_points.json       프레임별 점 좌표 frames[프레임][얼굴][점] = [x, y] 픽셀
    이름_points_overlay.mp4  원본 위 초록 얼굴 점 + 윤곽선
   가리기
    이름_cover.mp4         머리를 [가리기 색]으로 꽉 채움 (검정 · 초록 · 타원 · 네모, 카드로 고름)
    이름_headmask.mp4      흰 머리 / 검은 배경 마스크
   이름_settings.json      설정 · 입력 규격(input) · 결과 규격 대조(checks) · 프레임별 머리 박스 · 격자/표정 빠진 프레임 번호
  결과\verification.json    전체 클립 요약

■ 알아 둘 것
  격자·가리기: 머리 검출이라 정면·옆모습·뒤통수 모두 잡는다.
  표정 선·점: 눈·입이 보이는 정면~반측면만 잡힌다. 완전한 옆모습·뒤통수 프레임은 비어 있는 게 정상
           (settings.json 의 empty_face_frames 에 번호가 남는다).
  머리를 놓치는 컷: 세부 설정 › 검출 민감도 0.25 → 0.15 / 엉뚱한 곳에 생기면 0.35.

■ 가린 표정 가이드는 이렇게 만든다 (프레임마다)
  1. 머리 찾기   머리 검출 모델(YOLO11)이 머리 박스를 찾고, 추적기가 앞 프레임과 이어 붙인다
  2. 표정 찾기   머리 박스 부분만 잘라 256px 로 키운 뒤 MediaPipe 가 얼굴 점 478개를 찍는다
                 (멀리 있는 작은 얼굴도 잡히고, 뒤통수는 자연스럽게 빠진다)
  3. 가리기      얼굴 점의 바깥 테두리를 [윤곽 넓히기]만큼 넓힌 다각형을 가림 색으로 칠한다
                 [머리 전체]면 머리 박스를 둥근 네모로 칠한다. 표정을 못 찾은 머리도 이 네모로 칠한다
  4. 점·선       그 위에 얼굴 윤곽·눈·눈썹·입·코 선(1080p 기준 2px)과 점 478개를 점·선 색으로 찍는다
  5. 저장        원본 해상도·fps·색공간·소리 그대로 mp4 (+ 원하면 카드별 투명 레이어)

■ 다른 PC 에서
  폴더를 통째로 복사(zip 이면 [모두 압축 풀기] 뒤) → Griding.bat. 약 700MB.
  Windows 10/11 이면 된다. ComfyUI·파이썬·Visual C++ 설치·그래픽카드 없어도 됨
  (그래픽카드가 있으면 종류 상관없이 DirectML 로 자동으로 쓴다. 없으면 CPU 로 1.5~3배 느림).
  한글·공백이 들어간 폴더에 둬도 된다 (확인함).

  켤 때마다 [이 PC 점검] — 검은 창 · 화면 맨 위 '이 PC 점검' 에 같은 내용 (work\pc_check.json 에도 저장)
    ✓ 됨   ! 되지만 알아둘 것(일부 기능 꺼짐 · 느림)   ✗ 못 씀 → 무엇을 하면 되는지 같이 나온다
    운영체제 · CPU/메모리 · Visual C++ 런타임 · 프로그램 부품(numpy·opencv·onnxruntime·mediapipe·ffmpeg)
    ffmpeg 인코더(H.264 · PNG · AAC) · 모델 파일 4개 · 그래픽카드 이름과 DirectML · 표정 인식 켜짐 · 저장 폴더와 남은 공간
  없을 때 어떻게 되나
    빠른 머리 모델 · ffmpeg · 부품 없음   → 켜지 않고 '폴더를 통째로 다시 복사' 안내
    정확 모델 없음                      → '빠름' 만 (화면에서 정확이 꺼짐)
    표정 인식이 안 켜짐 (아주 오래된 CPU 등) → 표정 카드만 못 씀. 격자 · 머리 전체 가림은 됨
    그래픽카드 실행 실패 · 작업 중 드라이버 멈춤 → 자동으로 CPU 로 바꿔 이어서 처리
    앱 폴더에 쓸 수 없음 (Program Files · 읽기 전용) → 결과는 문서\Griding 결과, 임시는 %LOCALAPPDATA%\Griding 로 자동
    zip 안에서 바로 실행 → '압축을 먼저 푸세요' 안내

■ 구조 (객체 단위, app\facegrid\)
  settings  GridSettings(설정 검사 · 범위)                  patterns  Pattern → 모양별 클래스
  renderer  GridRenderer(격자 · 마스크 · 가리기)             detector  HeadDetector(머리 ONNX)
  guide     MaskedFaceGuide(가린 표정 가이드)
  tracker   Tracker · Track(박스 잇기 · HOLD)               facemesh  HeadCropFaceTracker · FaceLines · FacePoints
  media     VideoSource / ImageSource · FFmpegWriter · AlphaMovWriter · EncodeSpec
  probe     MediaInfo(입력 규격) · ColorSpec · OutputCheck(결과 대조)
  layers    Layer → 카드별 클래스 · Recipe · isolate(투명 레이어)   outputs   Output → 결과물별 클래스
  syscheck  Check → 점검별 클래스 · SystemCheck · SystemReport
  pipeline  FaceGridPipeline · JobSummary                    store     ResultStore · UploadStore
  jobs      JobQueue(순서대로 하나씩)                         gallery   Gallery(예시 카드)
  server    FaceGridApp(웹 서버)
  새 모양 = Pattern 상속 + REGISTRY 추가 / 새 결과물 = Output 상속 + OutputCatalog 추가
